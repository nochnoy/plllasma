# Документация

Ремейк флеш-игры [Free Falling Girl](https://www.arcadecabin.com/play/free_falling_girl.html) на
Vue 3 + PixiJS. Оригинал — фильм на ActionScript про тряпичную девушку, падающую в пустоте; порт
переносит из SWF её физику и риг, а сверху добавляет зал, чёрный фон вокруг него, тулбар и полоску
портретов в углах этого зала, верёвки.

Сам SWF и выгруженные из него материалы лежат в `assets-source/`, эталонные прогоны — в
`frontend/tests/data/`. Вся графика порта, кроме зала
(`frontend/public/assets/bg.png`) — его собственная добавка, — взята из оригинала; файл фильма хранится в
репозитории только как источник.

## Правила

- **Числа физики — из SWF.** Всё, что «на ощупь» (верёвка, поведение тулбара), живёт в слое
  сцены и объясняется комментарием рядом с константой.
- **В `frontend/src/game/vm/` нет добавок порта.** Так видно, что именно перенесено, а что придумано, и
  расхождение с эталоном сразу указывает на виновника.
- **Две зависимости времени выполнения** — `pixi.js` и `vue`; всё остальное (puppeteer, Ruffle)
  ставится через `npm i --no-save` и нужно только инструментам.
- **Языки:** интерфейс, README и эта папка — по-русски, комментарии в коде — по-английски.

## Проверка

```bash
cd frontend          # игра, её package.json и её node_modules — как в корневом README
npm run build        # vue-tsc --noEmit + vite build
npm test             # vitest: риг, эталонный прогон, верёвка, боль в позе, мир на экране, чат с его списком прогонов, покадровая лента и её срезы
cd ..                # смоук, отчёты и остальные инструменты живут в корне репозитория, рядом с tools/
node tools/smoke.mjs # собранная игра в Chromium: физика, тулбар, персонажи, полоска портретов, палец на экране, потолок, интерфейс внутри мира, чат с окном и списком прогонов, прогон, проигранный нажатием на его строку, прогон, который ещё играют, посмотренный с этой же страницы, покадровая лента (запись, воспроизведение ряд в ряд, рост под просмотром), скриншоты в tmp-smoke/
cd backend; go test ./...
                     # сервер: прогоны и их срезы, строки чата, список прогонов и лента через двери API (файл SQLite у каждой пробы свой)
```

Чат — единственное, что не живёт на одной странице: полоса и окно читают лог у сервера, а список прогонов
и лента выбранного — у него же (`air` в `backend/`, `:8080`), и без него всё это
остаётся пустым и говорит об этом в консоль. Как он устроен — в [`chat.md`](chat.md), и там же чем он
проверяется (в том числе тем, что смоук отвечает на семь дверей сервера сам — все, кроме здоровья и приёма
готового прогона, — отдавая и ленту, записанную в этом же прогоне, разрезанную на срезы для той двери, которой
живые срезы читают).

Правки в графике добавляют к этому `npm run assets:prepare`, а иконку страницы — `node tools/prepare-icon.mjs`;
подробности — в [`assets.md`](assets.md), правки в физике — в [`porting.md`](porting.md), разговор с
сохранённым прогоном — в [`tape.md`](tape.md), а разговор с другими игроками — в [`chat.md`](chat.md).
